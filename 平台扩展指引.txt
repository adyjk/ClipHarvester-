【平台扩展指引】

请按以下格式向 AI 提出平台接入需求：

```
【平台扩展请求】
目标：接入 [平台名称]（如：Bilibili / Xigua / 抖音 / 知乎）
需求细节：
1. API 接入方式：[RESTful / GraphQL / WebSocket]
2. 数据结构示例：[JSON / XML 格式示例]
3. 认证方式：[OAuth2 / API Key / Cookie]
4. 需要的功能：[抓取视频 / 图文 / 评论 / 点赞]
5. 其他特殊要求：[如：需支持翻页 / 需要登录态 / 需要反爬虫]

示例：
【平台扩展请求】
目标：接入 Bilibili
需求细节：
1. API 接入方式：RESTful
2. 数据结构示例：{
    "video": {
        "title": "示例视频",
        "url": "https://www.bilibili.com/video/xxx",
        "duration": 120,
        "summary": "视频摘要内容"
    }
}
3. 认证方式：OAuth2
4. 需要的功能：抓取视频及摘要
5. 其他特殊要求：需支持翻页
```

AI 处理原则：
1. 自动匹配：若已存在类似平台（如抖音/快手），会提示复用现有代码结构
2. 动态扩展：新增 `fetch-XXX` 命令并更新 `README.md`
3. 文档同步：自动更新 `docs/` 目录下的平台说明
4. 安全检查：确认无敏感信息泄露后才执行代码修改

常见扩展类型示例：
- `fetch-bilibili 20` - 抓取 20 条 Bilibili 视频
- `fetch-xigua 15` - 抓取 15 条西瓜视频
- `fetch-zhihu 10` - 抓取 10 条知乎图文
- `fetch-tieba 30` - 抓取 30 条贴吧热帖

请直接粘贴你的平台接入需求，我会基于项目文档和代码给出详细解答。
